# Scam cards

A scam card is a short write-up of one scam repo on GitHub: what it promises, how the scam works, the red flags, and what to do if you already ran it.

- **One card per repo.**
- **Evidence with file:line.** Every claim points to the file and line where we saw it (for example `README.md line 9` or `index.html line 1`).
- **Read-only research.** Repos are checked only through the GitHub API. Nothing from a suspect repo is downloaded, cloned or run.
- **Links are defanged.** Attacker URLs are written like `hxxps://example[.]com` so they can't be clicked.
- **Repo names are plain text**, not links, so these pages don't send traffic to malware.
- A card says "likely scam" unless readable code proves it is malware.
